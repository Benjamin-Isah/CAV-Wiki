## Owner approval record for each file

- [ ] The exact original file and its author/rightsholder are identified.
- [ ] The grant expressly covers display and redistribution on this unofficial wiki; record its scope and date.
- [ ] Confirm whether cropping, cutout extraction, resizing, WebP conversion, and derivative generation are permitted. Default to no crop and no invented reconstruction.
- [ ] Record required attribution, license text, destination/source URL, expiry, and restrictions. Do not label a custom grant “Creative Commons” unless it is.
- [ ] Keep private correspondence outside the public bundle; place a non-sensitive reference to the permission record in the manifest.
- [ ] Verify that the subject is the correct Calling All Villains version of the character.
- [ ] Write alt text for the actual supplied file. Candidate descriptions above are reference notes, not final alt text for an unseen asset.
- [ ] Confirm original dimensions and optimize without distorting proportions or removing important details.
- [ ] Add the file to `public/images/` and register its approved metadata centrally. Do not hotlink third-party image CDNs.

Until those items are satisfied, the redesign should use an honest text-based record treatment and a link to the official reference. It must not imply that an empty image slot is a canonical silhouette or replace a missing asset with AI-generated character art.
