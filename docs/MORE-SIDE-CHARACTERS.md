# More side characters

Updated 1 November 2026 following the request to add more side characters. Eight new roster-cameo articles bring the wiki to 30 articles, 23 character-category articles, and 25 character-directory entries. Background villains now contains 14 entries.

## Added entries

Reaper villain, Red-and-black villain, Mechanical reptile villain, Radio villain, Crowned cat villain, White-haired villain, Red-haired villain, and Object-headed villain. These are descriptive labels, not verified personal names. Articles record visible design details and keep unknown identities, powers, relationships and episode events unconfirmed. No unverified deaths, genders, backstories or voice actors were copied from community descriptions.

The reviewed [community image index](https://calling-all-villains.fandom.com/wiki/Minor_Characters_(Calling_All_Villains)) provides the visual references. The [official pilot](https://www.youtube.com/watch?v=3AFJtcP2cp0) remains the primary episode source. New appearance notes cite the community reference separately and use editorial evidence labels. A clearer primary naming reference is still needed before renaming these entries to personal names. The source crop catalogued as Unknown Villain 7 is described by visible red-and-black forms; the community's creature interpretation was not treated as canon.

## Presentation

Every new article has a local portrait, infobox, required character sections, gallery, source notes, and related reading. The homepage spotlights several additions and its update list records actual new articles. The Coffin villain page now links to new background-character entries. Existing category filters, A–Z sorting, aliases, full-text search, routes, statuses, and article-only videos remain. No runtime dependency or new service was added.

## Image provenance

Files were obtained through images observed in normal browser pages, following the owner's continuing instruction to find real character art online. Each downloaded source is preserved unchanged as WebP; no AI generation, retouching, or extrapolation was used. Small portraits use the existing roster framing to avoid excessive enlargement. Tiny mask-pair, crystal and strawberry crops were inspected but not integrated because they lacked clear detail.

Rights status is unverified. The source site and the owner's request do not establish a verified reuse license; no asset is marked approved or licensed. All sources, dimensions, credits, alt text and usage notes are in supporting-images.ts.
